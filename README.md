# Road Care

وب‌اپ مدیریت سوخت، ناوگان و نگهداری (PWA).

## اجرا
فایل `index.html` را در مرورگر باز کنید، یا با GitHub Pages منتشر کنید:
Settings → Pages → Branch: `main` / root

## فایل‌ها
- `index.html` — برنامه اصلی
- `manifest.json` — تنظیمات نصب PWA
- `care-icon-192.png`, `care-icon-512.png` — آیکون‌ها
